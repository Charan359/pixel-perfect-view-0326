# Media placeholders

Drop your files here with these EXACT names (no code changes needed):

- memory01.jpg ... memory20.jpg  — one photo per candle (jpg, ideally portrait, ~1200px wide)
- finalBirthdayVideo.mp4         — the closing 2–3 minute video
- music.mp3                      — optional background music (use your own / royalty-free)

Any file that is missing simply shows an elegant placeholder instead.
Captions and text live in `src/lib/experience-content.ts`.
